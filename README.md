# 音乐雷达：完整音频核验本地版

## iOS 完全独立版（2026-11-28）

- 未签名 IPA（390534 字节，sha256 `eecb78512cd88b4ec8134d2022b24de54a60935b298f8ebefad1c719f36ce195`）：[GitHub Releases](https://github.com/WASDDDD/music-radar/releases/tag/ios-standalone-v1.0)

本机地址：http://127.0.0.1:18772/

这是可运行的本地成品。GitHub、Netlify 和此前的正式页面没有更新。不要用旧线上网址检查本次改动。

## 启动

需要 Node.js 24+、ffmpeg、ffprobe。本机已安装。不需要 npm install。

在本目录运行：

```sh
bash 启动.sh
```

默认只监听本机 127.0.0.1，端口 18772。浏览器打开上面的地址。网页和播放后端必须一起启动，单独打开 HTML 文件不能使用新播放通道。当前 DSH 会话已经启动了服务，重复启动会提示端口被占用。

## 播放逻辑

- QQ 使用新版 `music.vkey.GetVkey / UrlGetVkey`；酷狗使用官方 `get_song_info` 播放地址，替换了此前返回空内容的第三方播放通道。
- 首次选歌先获取整个音频文件，核对实际时长与目录时长，再做整文件解码和独立尾段解码。通过之后才交给浏览器播放。
- 原源不可用时，在网易、QQ、酷狗之间查找名称、歌手一致且音频时长接近的候选；匹配成功时明确标注实际音源及“同名同歌手匹配”。这是目录资料和音频时长的匹配，不是录音指纹鉴定，不能保证专辑母带完全相同。不会换成同名翻唱或把几十秒试听标成完整原唱。
- 网易/QQ/酷狗播放页显示实际音源及实测时长。下载所选网易/QQ/酷狗歌曲也使用同一已核验文件；没有虚构无损音质。
- 已核验的完整音频缓存在本机运行目录。浏览器读取本机缓存，支持 Range 分段、拖动进度及尾段播放。重启后会重新校验，不依赖已过期的临时 CDN 链接。
- 保留 MIUIX/液态玻璃切换、歌词动效、个人歌单、书签、搜索分页及滚动动画。

## 实际验收

- 罗言RollFlash《冬天又来临》：QQ 和酷狗分别取得原源文件，FFprobe 测得 169.430204 秒，整文件与尾段解码通过。Via 手机浏览器实测约 169.384603 秒，均在拖动到尾段后触发自然 ended 事件。
- 许嵩《有何不可》：QQ/酷狗原源未提供完整地址，匹配到网易同歌手同曲名版本，FFprobe 测得 241.867755 秒；Via 浏览器实测约 241.840816 秒并自然播完。页面明确标注网易。
- 额外抽测 QQ/酷狗各 4 首：陈奕迅《富士山下》《孤勇者》和许嵩《有何不可》共 6 个入口通过完整文件与尾段解码；实际均为明确标出的网易候选。《富士山下》258.951837 秒，《孤勇者》256.032 秒。两个平台的《晴天》入口均仍返回授权不足，未伪装为成功。
- 前后端完整性、失败提示、切歌请求取消、浏览器自动播放恢复、CSP 哈希、原搜索分页和个人歌单重载恢复测试通过。

## 真实边界

这不是“任何平台任何付费歌曲免授权播放”。例如本次测试的周杰伦原唱《晴天》，原源未提供完整播放地址，也没有找到通过目录与时长核验的免费候选，接口明确返回 `RIGHTS_REQUIRED`，不会冒充成功。此类曲目仍需要合法的播放授权或用户有权使用的完整文件。

汽水候选中的部分结果虽然标记 preview=false，实际是短翻唱；没有把这些结果混入原唱兜底。

第一次核验要消耗整首歌曲的流量，可能比直接播放慢。后端停止时本地地址会不可用，需要重新启动。此版尚未部署到公网；若后续部署，必须同时部署具备 Node 和 ffmpeg 的后端，不能只上传 HTML。

新本机端口与旧网站的浏览器存储相互独立。既有线上歌单没有被改动；本地版新建的歌单仍只保存在当前浏览器、当前站点。

## 音源兜底链（2026-11-23 扩充）

播放优先级：**原始平台官方接口 → 网易同名同歌手 → QQ/酷狗 → JOOX → 酷我**。

新增两条可用通道（都经过 ffprobe 实际时长 + 整文件解码 + 尾段解码三重核验）：

- **JOOX**（经 GD Studio `music-api.gdstudio.xyz`）：解决《春涧·浅影阿》这类国内平台付费曲。取链偶发空响应，代码内带重试。
- **酷我**（`mobi.kuwo.cn/mobi.s` + DES 加密 `convert_url2`）：覆盖面最大，QQ/酷狗/网易付费曲基本都能拿到完整 320k/128k mp3。搜索必须带 `show_copyright_off=1`，否则搜不到付费曲。

### 酷我也是搜索源

搜索源切换条现在是四个：**搜 网易云 / 搜 QQ音乐 / 搜 酷狗 / 搜 酷我**。

酷我不走 meting 镜像（镜像不支持），走本机后端自建接口：

- `/.netlify/functions/search?source=kuwo&keyword=<词>&limit=<1-60>&page=<0起>` → 数组，每项 `{id,name,artist,album,pic,url:'kuwo://track?id=<id>',lrc,server:'kuwo',duration}`。
- `/.netlify/functions/lyric?source=kuwo&id=<id>` → `text/plain` 的 LRC 文本（含 `[mm:ss.xx]` 行）。
- 播放仍走 `/.netlify/functions/playback?source=kuwo&id=<id>`，同一套三重核验。
- 封面用 `https://img1.kuwo.cn/star/albumcover/...`（`img1.kwcdn.kuwo.cn` 的证书域名不匹配，会 ERR_CERT_COMMON_NAME_INVALID）。
- 酷我搜索返回的是单引号伪 JSON，字段名是 `abslist[].NAME`（不是 `SONGNAME`）。

实测（10 首热门 + 换源）：晴天、孤勇者、我怀念的、愿与愁、有何不可、海屿你、起风了、富士山下、稻香、春涧 —— **10/10 全部完整播放**。

注意：换源的曲目界面会标注真实来源平台（如「酷我 · 完整 4:29」），并提示是「同名同歌手匹配」，不是原平台母带。
